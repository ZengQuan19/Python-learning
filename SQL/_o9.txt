=== 0. 三种连接方式 ===
   ① sqlite3 连接        -> read_sql ✅   to_sql ✅   （pandas 官方支持）
   ② pymysql 裸连接      -> read_sql ⚠️可用但报警告 / to_sql ❌ 直接报错
   ③ SQLAlchemy engine   -> read_sql ✅   to_sql ✅   无警告（推荐）

   连接串（密码已打码）: mysql+pymysql://root:***@localhost:3306/practice?charset=utf8mb4

=== 1. pd.read_sql：SQL 进去，DataFrame 出来 ===
 order_id  user_id  product_id  quantity  amount    status order_date
        1       11         101         1   399.0 cancelled 2024-09-08
        2        4         102         1   129.0 cancelled 2024-12-18
        3        2         105         3   477.0      paid 2024-07-03

   dtypes 长这样：
   order_id        int64
   user_id         int64
   product_id      int64
   quantity        int64
   amount        float64
   status            str
   order_date     object
   ⚠️ order_date 是 object，不是日期类型 —— 所以后面要 pd.to_datetime 转一下

=== 2. 参数化：params 传字典，防止 SQL 注入 ===
   用户 4 的订单： [2, 4, 13, 15, 20, 22, 37]
   总额： 2990.0

=== 3. 月度 GMV + 环比：纯 SQL vs SQL+pandas ===
   路 A（纯 SQL）：
        ym    gmv   mom
   2024-07 1681.0   NaN
   2024-08 3182.0  89.3
   2024-09 5174.0  62.6
   2024-10 1497.0 -71.1
   2024-11 1256.0 -16.1
   2024-12 1132.0  -9.9

   路 B（pandas）：
     gmv: [1681.0, 3182.0, 5174.0, 1497.0, 1256.0, 1132.0]
     环比: [nan, 89.3, 62.6, -71.1, -16.1, -9.9]
   -> 第一行的环比是 NaN（没有上个月可对比），和 SQL 的 NULL 是一个意思

=== 4. 对账（这是本课最重要的动作）===
   GMV 一致吗： True
   环比一致吗： True
   -> 两条路都对，才说明你两边都没写错。做不到一致就是有 bug。

=== 5. df.to_sql：DataFrame 写回 MySQL ===
   写回再读回：
        ym    gmv  mom_pct
   2024-07 1681.0      NaN
   2024-08 3182.0     89.3
   2024-09 5174.0     62.6
   2024-10 1497.0    -71.1
   2024-11 1256.0    -16.1
   2024-12 1132.0     -9.9
   -> 这就是「结果落表」：分析结果存进数据库，别人（或报表工具）就能直接用。

=== 6. 分工判断表 ===
   数据量很大，只想要其中一部分          -> SQL（WHERE 在数据库里筛，别全捞回来）
   分组聚合、排名、画窗口                -> 都行，SQL 更省内存
   要算「买了 A 又买了 B」的交叉分析      -> pandas 更灵活（pivot / merge）
   要画图、导出 Excel、做机器学习        -> 只能 pandas
   要定期跑、结果落表给业务用            -> SQL 写死，pandas 只做校验

   经验法则：**能用 SQL 筛掉的，别捞进 pandas 再筛。**
   十万行以内随你怎么写都行；上百万行时，这一条就是性能的分水岭。
